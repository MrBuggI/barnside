# Barnside — Animal Habits

**Barnside** — мод для Minecraft Java Edition, который оживляет ферму, добавляя привычки и новое поведение ванильным животным. Они запоминают знакомые места, следуют распорядку дня и постепенно привыкают к игроку.

Главная идея — сделать животных полноценными обитателями фермы. Построенный курятник становится местом, куда куры возвращаются вечером, гнёзда — местом для кладки яиц, а кормушка — точкой, вокруг которой собираются животные. Поведение раскрывается через обычную игру, без сложных меню и обязательного управления каждым животным.

## Первая версия: куры

Планируемые механики:

- **Гнёзда.** Куры выбирают гнездо и возвращаются к нему, чтобы откладывать яйца. Если оно разрушено или недоступно, ищут другое.
- **Сон и насесты.** Вечером куры ищут подходящее место для ночлега, а утром возвращаются к обычным занятиям.
- **Кормушки.** Привлекают кур и помогают организовать пространство фермы.

Если подходящих условий нет, животные сохраняют обычное поведение Minecraft. Новые механики дополняют существующие фермы и дают повод обустраивать их.

## Принципы проекта

- **Близость к ванильному Minecraft.** Знакомые животные, простые взаимодействия и визуальный стиль, подходящий игре.
- **Заметное поведение.** Привычки должны быть понятны по действиям животных.
- **Уют без рутины.** Без обязательного голода, болезней и ежедневного обслуживания.
- **Работа в существующих мирах.** Возможность обустроить ферму вокруг уже имеющихся животных.
- **Бережное использование ресурсов.** Ограниченный поиск мест и периодическое обновление поведения.

## Дальнейшее развитие

После первой версии планируется добавить узнавание кормящего игрока и постепенно расширять мод на других животных. Каждый вид получит собственные привычки: свиньи смогут искать еду в земле, овцы — собираться вместе во время дождя, коровы — возвращаться к знакомому месту кормления.

*Проект находится в разработке. Перечисленные механики описывают концепцию и планы, а не готовые возможности.*
